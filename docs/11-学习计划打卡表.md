## 打卡纪律（给你自己定的）

1. **每周留一份 retro 笔记**：学了什么、卡在哪、下周改啥。
2. **红比绿重要**：评测红了才是你学到东西的时候，别为了绿而绿。
3. **卡超过 2 天就回看对应文档 + 原文**，别硬憋。
4. **12 周不是考试**：P1–P3 是硬门槛必过；P4–P5 尽力，但 P5 平台原型尽量跑到 M3。

> 全部打勾那天，你就不再是"想转 Agent 测试的自动化工程师"，而是"已经搭起自己 Agent 测试平台的 AI QE"。
