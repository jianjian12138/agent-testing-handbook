## 10.4 Benchmark（建立基线的标尺）

| Benchmark | 测什么 |
| --- | --- |
| **WebArena / MiniWoB++** | Web 操作类 Agent 任务完成度 |
| **TAU-bench** | 工具调用 Agent 多轮任务（含用户模拟） |
| **AgentBench** | 多环境综合 Agent 能力 |
| **OSWorld** | GUI 操作类 |
| **τ-bench / ToolBench** | 工具调用可靠性 |
| **Spider / BIRD** | (传统) Text-to-SQL，可作工具质量基线 |

> 注意：Benchmark 是"通用基线"，你业务里的"真准出标准"还得靠自己数据集（文档 05）。别用 Benchmark 分数当发布依据。
